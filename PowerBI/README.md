# Power BI Dashboard

This folder contains the Power BI dashboard developed from the outputs of the FPL analytics model.

## Overview

Power BI is used to transform the analytical model into an interactive decision-support dashboard for exploring player performance, fixtures, value and squad selection.

## Dashboard Pages

### FPL Overview

Provides a high-level view of the FPL dataset and model outputs, including:

- Player rankings
- Top goal scorers
- Top assist providers
- Price versus model expected points
- Player value

### Player Analysis

Allows individual players to be investigated using:

- Model expected points
- Price
- Points per 90
- Minutes
- Expected points per £m
- Fixture outlook
- Player rankings

### Squad Optimisation

Displays the model-selected 15-player squad and evaluates:

- Squad cost
- Remaining budget
- Expected points
- Squad size
- Squad composition
- Expected points by position

## Main File

`FPL_Analytics_Dashboard.pbix`

The Power BI dashboard provides the interactive presentation layer for the underlying Excel analytics model.
