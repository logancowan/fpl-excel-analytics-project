# Excel FPL Analytics Model

This folder contains the Excel-based analytical and squad optimisation model used in the project.

## Overview

The Excel model acts as the main analytical engine of the project. It combines player performance data, statistical metrics, fixture analysis and squad constraints to evaluate Fantasy Premier League players and construct an optimised squad.

## Key Analysis

The model includes:

- Player performance analysis
- Points and expected performance metrics
- xG, xA and xGI analysis
- Player value analysis
- Fixture difficulty and fixture adjustments
- Player ranking
- Expected points modelling
- Squad optimisation
- FPL squad constraint checks

  ## Main Workbook

`FPL_Analytics_Model.xlsx`
The workbook contains the underlying data, calculations, player model, fixture analysis and squad optimisation used to generate the outputs presented in the Power BI dashboard.
